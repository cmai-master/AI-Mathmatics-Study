1. Linear Algebra for AI

1.1 Matrix Decompositions

Singular Value Decomposition (SVD):

For any matrix \(A \in \mathbb{R}^{m \times n}\), there exists a decomposition:

$$A = U\Sigma V^T$$

where:

  • \(U \in \mathbb{R}^{m \times m}\): orthogonal matrix (left singular vectors)
  • \(\Sigma \in \mathbb{R}^{m \times n}\): diagonal matrix (singular values)
  • \(V \in \mathbb{R}^{n \times n}\): orthogonal matrix (right singular vectors)

1.2 Eigenvalues and Eigenvectors

Spectral Theorem:

If \(A\) is a real symmetric matrix, then \(A\) has an eigendecomposition:

$$A = Q\Lambda Q^T$$

where \(Q\) is orthogonal and \(\Lambda\) is diagonal with real eigenvalues.

2. Probability Theory and Statistics

2.1 Probability Distributions

Gaussian Distribution:

The univariate Gaussian (normal) distribution:

$$\mathcal{N}(x|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

Multivariate Gaussian:

$$\mathcal{N}(\mathbf{x}|\boldsymbol{\mu}, \boldsymbol{\Sigma}) = \frac{1}{\sqrt{(2\pi)^n|\boldsymbol{\Sigma}|}} \exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^T\boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})\right)$$

2.2 Bayes' Theorem

Bayes' Theorem:
$$P(\theta|D) = \frac{P(D|\theta)P(\theta)}{P(D)}$$

where:

  • \(P(\theta|D)\): Posterior probability
  • \(P(D|\theta)\): Likelihood
  • \(P(\theta)\): Prior probability
  • \(P(D)\): Evidence (marginal likelihood)

3. Optimization Theory

3.1 Gradient Descent

Gradient Descent Update Rule:
$$\mathbf{x}_{k+1} = \mathbf{x}_k - \alpha \nabla f(\mathbf{x}_k)$$

where \(\alpha > 0\) is the learning rate (step size).

3.2 Momentum Methods

Momentum Update:
$$\begin{aligned} \mathbf{v}_{k+1} &= \beta \mathbf{v}_k - \alpha \nabla f(\mathbf{x}_k)\\ \mathbf{x}_{k+1} &= \mathbf{x}_k + \mathbf{v}_{k+1} \end{aligned}$$

where \(\beta \in [0,1)\) is the momentum coefficient.

3.3 Convexity

Convex Function:

A function \(f\) is convex if for all \(\mathbf{x}, \mathbf{y}\) and \(\lambda \in [0,1]\):

$$f(\lambda \mathbf{x} + (1-\lambda)\mathbf{y}) \leq \lambda f(\mathbf{x}) + (1-\lambda)f(\mathbf{y})$$

4. Information Theory

4.1 Entropy

Shannon Entropy:

For a discrete random variable \(X\) with probability mass function \(p(x)\):

$$H(X) = -\sum_{x \in \mathcal{X}} p(x) \log_2 p(x) = \mathbb{E}[-\log_2 p(X)]$$

Measured in bits (log base 2) or nats (natural log).

4.2 KL Divergence

Kullback-Leibler Divergence:
$$D_{KL}(P \| Q) = \sum_{x} P(x) \log \frac{P(x)}{Q(x)} = \mathbb{E}_P\left[\log \frac{P}{Q}\right]$$

Properties:

  • \(D_{KL}(P \| Q) \geq 0\) (Gibbs' inequality)
  • \(D_{KL}(P \| Q) = 0 \iff P = Q\)
  • NOT symmetric: \(D_{KL}(P \| Q) \neq D_{KL}(Q \| P)\)

5. Statistical Learning Theory

5.1 Bias-Variance Tradeoff

Bias-Variance Decomposition:

For squared loss:

$$\mathbb{E}[(y - \hat{h}(x))^2] = \text{Bias}^2(\hat{h}(x)) + \text{Var}(\hat{h}(x)) + \sigma^2$$

where:

  • \(\text{Bias}(\hat{h}(x)) = \mathbb{E}[\hat{h}(x)] - h^*(x)\)
  • \(\text{Var}(\hat{h}(x)) = \mathbb{E}[(\hat{h}(x) - \mathbb{E}[\hat{h}(x)])^2]\)
  • \(\sigma^2\) = irreducible error

6. Deep Learning Mathematics

6.1 Activation Functions

Interactive: Activation Functions

Compare different activation functions and their derivatives

Sigmoid: \(\sigma(x) = \frac{1}{1+e^{-x}}\)

  • Range: (0, 1)
  • Problem: Vanishing gradients
  • Use case: Binary classification output

Tanh: \(\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}\)

  • Range: (-1, 1)
  • Zero-centered (better than sigmoid)
  • Still suffers from vanishing gradients

ReLU: \(\text{ReLU}(x) = \max(0, x)\)

  • Range: [0, ∞)
  • No vanishing gradient for x > 0
  • Problem: Dying ReLU (neurons can "die")
  • Most popular in practice

GELU: \(\text{GELU}(x) = x \cdot \Phi(x)\)

  • Smooth approximation of ReLU
  • Used in Transformers (BERT, GPT)
  • Better performance in many tasks

6.2 Backpropagation

Backpropagation Algorithm:

For a network with layers \(\ell = 1, \ldots, L\):

$$\begin{aligned} \text{Forward: } & z^{(\ell)} = W^{(\ell)}a^{(\ell-1)} + b^{(\ell)}, \quad a^{(\ell)} = \sigma(z^{(\ell)})\\ \text{Backward: } & \delta^{(L)} = \nabla_a \mathcal{L} \odot \sigma'(z^{(L)})\\ & \delta^{(\ell)} = ((W^{(\ell+1)})^T \delta^{(\ell+1)}) \odot \sigma'(z^{(\ell)})\\ \text{Gradients: } & \frac{\partial \mathcal{L}}{\partial W^{(\ell)}} = \delta^{(\ell)}(a^{(\ell-1)})^T \end{aligned}$$

7.3 Derivation Problems

Problem 1: Derive the gradient of the quadratic form \(\frac{1}{2}\mathbf{x}^T A \mathbf{x}\) where \(A\) is symmetric.

Solution:

Let \(f(\mathbf{x}) = \frac{1}{2}\mathbf{x}^T A \mathbf{x}\)

Using the definition of gradient:

$$\frac{\partial f}{\partial x_i} = \frac{\partial}{\partial x_i}\left(\frac{1}{2}\sum_j \sum_k x_j A_{jk} x_k\right)$$ $$= \frac{1}{2}\left(\sum_k A_{ik}x_k + \sum_j x_j A_{ji}\right)$$

Since \(A\) is symmetric, \(A_{ji} = A_{ij}\):

$$= \frac{1}{2}(A\mathbf{x} + A^T\mathbf{x}) = \frac{1}{2}(A\mathbf{x} + A\mathbf{x}) = A\mathbf{x}$$

Therefore: \(\nabla f(\mathbf{x}) = A\mathbf{x}\)

Problem 2: Prove that \(D_{KL}(P \| Q) \geq 0\) with equality if and only if \(P = Q\).

Solution (Gibbs' Inequality):

We use Jensen's inequality. Since \(-\log\) is convex:

$$-D_{KL}(P \| Q) = \sum_x P(x) \log \frac{Q(x)}{P(x)} = \mathbb{E}_P\left[\log \frac{Q}{P}\right]$$ $$\leq \log \mathbb{E}_P\left[\frac{Q}{P}\right] = \log \sum_x P(x) \frac{Q(x)}{P(x)} = \log \sum_x Q(x) = \log 1 = 0$$

Therefore: \(D_{KL}(P \| Q) \geq 0\)

Equality holds iff \(\frac{Q(x)}{P(x)}\) is constant for all \(x\) with \(P(x) > 0\).

Since \(\sum Q(x) = \sum P(x) = 1\), this constant must be 1, so \(P = Q\).
